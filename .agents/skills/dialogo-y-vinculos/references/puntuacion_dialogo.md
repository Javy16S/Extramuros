# Puntuación de diálogos en español (RAE, *Ortografía de la lengua española*, 2010)

| Caso | Correcto |
|---|---|
| Intervención simple | `—Tengo hambre.` |
| Verbo de habla detrás | `—Tengo hambre —dijo Leo.` |
| Verbo de habla y la frase sigue | `—Tengo hambre —dijo Leo—, y no pienso comer eso.` |
| Verbo de habla y nueva oración | `—Tengo hambre —dijo Leo—. Y no pienso comer eso.` |
| Acción (no verbo de habla) detrás | `—Tengo hambre. —Leo miró la carne cruda.` |
| Acción en medio, nueva oración | `—Tengo hambre. —Leo miró la carne cruda—. No pienso comer eso.` |
| Pregunta o exclamación + acotación | `—¿Dónde estoy? —preguntó.` (sin punto tras el signo de cierre) |
| Exclamación + acción | `—¡Dispara! —El agente sacó el arma.` |
| Puntos suspensivos + acotación | `—Aceptar... —susurró Leo.` |
| Intervención que acaba en raya de cierre | Nunca se cierra con raya si no sigue texto: `—Vámonos —dijo.` (no `—dijo—`) |
| Cita dentro de diálogo | `—Me dijo: «No la pierdas».` (comillas angulares, punto fuera) |
| Pensamiento | En cursiva, sin raya: *No aguanta otro golpe.* |
| Recuerdo de una frase dicha | Cursiva o comillas angulares, coherente en todo el libro. El cap. 1 usa cursiva + comillas: elige uno. |

## Errores típicos a corregir
- Guion corto (-) o raya de longitud incorrecta (–). La raya es «—».
- Espacio entre la raya y el texto del diálogo: `— Hola` ✗ → `—Hola` ✓.
- Punto antes de la raya con verbo de habla: `—Hola. —dijo.` ✗ → `—Hola —dijo.` ✓
- Mayúscula tras raya con verbo de habla: `—Hola —Dijo.` ✗
- Verbo de habla que no es de habla: `—Hola —sonrió.` → se considera incorrecto si el verbo no denota habla; mejor `—Hola. —Sonrió.` o `—Hola —dijo, sonriendo.` (cuidado con el gerundio).
